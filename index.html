문제 1: 상수의 이해

다음 중 올바른 코드를 고르세요.

// A)
const int NUM = 10;
NUM = 20;

// B)
#define PI 3.14
PI = 3.141592;

// C)
const int AGE = 20;
printf("%d", AGE);

힌트: 상수는 값을 변경할 수 없어요!

정답: C

해설:

// A) ❌ 오답
const int NUM = 10;
NUM = 20;  // 에러! const 상수는 값 변경 불가

// B) ❌ 오답
#define PI 3.14
PI = 3.141592;  // 에러! 매크로 상수는 값 변경 불가

// C) ✅ 정답
const int AGE = 20;
printf("%d", AGE);  // 올바른 사용법

핵심 정리:

  • const (심볼릭 상수)와 #define (매크로 상수) 모두 선언 후 값 변경 불가
  • 상수는 읽기만 가능하고, 값을 대입하려고 하면 컴파일 에러 발생

문제 2: 형식 문자 활용

변수를 선언하고 다음과 같이 출력되도록 프로그램을 작성하세요.

문자: A
10진수: 65
16진수: 41

힌트: 같은 변수를 %c, %d, %x로 출력하면 돼요!

#include <stdio.h>

int main(void) {
    char ch = 'A';
    
    printf("문자: %c\n", ch);      // A
    printf("10진수: %d\n", ch);    // 65 (ASCII 코드)
    printf("16진수: %x\n", ch);    // 41 (65의 16진수)
    
    return 0;
}

해설:

  • %c: 문자로 출력 → 'A'
  • %d: 10진수로 출력 → 65 (문자 'A'의 ASCII 코드값)
  • %x: 16진수로 출력 → 41 (65를 16진수로 변환)

핵심 정리:

  • 같은 변수도 형식 문자에 따라 다르게 출력됨
  • 문자는 내부적으로 정수(ASCII 코드)로 저장됨

문제 3: 소수점 출력 제어

실수형 변수 pi에 3.141592를 저장하고, 다음과 같이 출력하세요.

기본: 3.141592
소수 둘째자리: 3.14
폭 15칸, 오른쪽정렬, 소수 셋째자리: ________3.142

힌트: %.2f, %15.3f 같은 형식을 사용하세요!

#include <stdio.h>

int main(void) {
    double pi = 3.141592;
    
    printf("기본: %f\n", pi);
    printf("소수 둘째자리: %.2f\n", pi);
    printf("폭 15칸, 오른쪽정렬, 소수 셋째자리: %15.3f\n", pi);
    
    return 0;
}

실행 결과:

기본: 3.141592
소수 둘째자리: 3.14
폭 15칸, 오른쪽정렬, 소수 셋째자리:           3.142

해설:

  • %f: 기본 소수점 6자리까지 출력
  • %.2f: 소수점 둘째자리까지 출력 (반올림)
  • %15.3f: 전체 폭 15칸, 오른쪽 정렬, 소수점 셋째자리까지
  • %-15.3f: 왼쪽 정렬로 바뀜

핵심 정리:

  • %폭.소수자리수f 형식으로 출력 제어
  • 음수(-) 붙이면 왼쪽 정렬

문제 5: 형변환 실습 ⭐

다음 코드의 출력 결과를 예측하고, 직접 실행해서 확인해보세요.

#include <stdio.h>

int main(void) {
    int a = 10;
    double b = 3.7;
    
    printf("a + b = %f\n", a + b);
    printf("(int)b = %d\n", (int)b);
    printf("a / 3 = %d\n", a / 3);
    printf("a / 3.0 = %f\n", a / 3.0);
    
    return 0;
}

질문: 왜 a / 3과 a / 3.0의 결과가 다를까요?

실행 결과:

a + b = 13.700000
(int)b = 3
a / 3 = 3
a / 3.0 = 3.333333

해설:

  • a + b = 13.700000
    • int(10) + double(3.7) → 자동형변환으로 int가 double로 변환
    • 10.0 + 3.7 = 13.7
  • (int)b = 3
    • 강제형변환: 3.7을 int로 변환
    • 소수점 이하 버림 → 3
  • a / 3 = 3
    • 정수 ÷ 정수 = 정수 (소수점 버림)
    • 10 ÷ 3 = 3 (나머지 1 버림)
  • a / 3.0 = 3.333333
    • 정수 ÷ 실수 = 실수 (자동형변환)
    • 10.0 ÷ 3.0 = 3.333333...

핵심 정리:

  • 자동형변환: 정수와 실수 연산 시 정수가 실수로 자동 변환
  • 강제형변환: (자료형)값 형식으로 개발자가 직접 변환
  • 정수 나눗셈: 정수끼리 나누면 결과도 정수 (소수점 버림)
  • 실수 나눗셈: 하나라도 실수면 결과는 실수

추가 팁:

// 정수 나눗셈을 실수로 얻고 싶다면?
int x = 10, y = 3;
printf("%f\n", (double)x / y);  // 3.333333
printf("%f\n", x / (double)y);  // 3.333333
printf("%f\n", (double)(x / y)); // 3.000000 (이미 나눈 후 변환)

문제 2: 전위/후위 증감 연산자 결과 예측

다음 코드의 실행 결과를 예측하고, 그 이유를 설명하세요.

int a = 5, b = 5;
printf("%d\n", ++a);  // (1)
printf("%d\n", a);    // (2)
printf("%d\n", b++);  // (3)
printf("%d\n", b);    // (4)

정답:

(1) 6  → 전위 증감(++a)이므로 먼저 1 증가 후 출력
(2) 6  → a는 이미 6
(3) 5  → 후위 증감(b++)이므로 먼저 출력 후 1 증가
(4) 6  → b는 출력 후 증가했으므로 6

해설: 전위 연산자(++a)는 증가 먼저 → 사용, 후위 연산자(a++)는 사용 먼저 → 증가

문제 3: 짝수/홀수 판별

문제 5: 복합 연산 결과 예측

다음 코드의 최종 result 값을 계산하세요.

int x = 10, y = 5;
int result = x++ * 2 + --y;
printf("result: %d\n", result);
printf("x: %d, y: %d\n", x, y);

정답:

result: 24
x: 11, y: 4

계산 과정:

  • x++는 후위 증감이므로 현재 값 10 사용 → x는 나중에 11로 증가
  • --y는 전위 증감이므로 먼저 4로 감소 → 4 사용
  • 계산: 10 * 2 + 4 = 24
  • 최종: x는 11, y는 4

해설: 연산자 우선순위는 전위증감(--) → 곱셈(*) → 덧셈(+) → 후위증감(++) 순입니다.

callDiffByRef: Call-by-reference 방식으로 두 수 중에서 큰 것을 number1에, 작은 것을 number2에 저장하는 함수 (number1에 저장된 정수가 더 큰 경우 변화가 없으나, number2에 저장된 정수가 더 큰 경우 교환)

HINT: Call-by-reference 함수의 매개 변수를 선언할 때는 포인터 연산자를 사용합니다.

#include <stdio.h>

int getDiffByValue(int num1, int num2) {
    return (num1 > num2) ? (num1 - num2) : (num2 - num1);
}

void callDiffByRef(int *num1, int *num2) {
    if (*num2 > *num1) {
        int temp = *num1;
        *num1 = *num2;
        *num2 = temp;
    }
}

int main(void) {
    int number1 = 10, number2 = 20;
    printf("차이: %d\n", getDiffByValue(number1, number2));
    callDiffByRef(&number1, &number2);

    return 0;
}

문제 5: 할당된 영역의 크기가 가장 큰 포인터 고르기

다음 코드에서 동적 메모리 할당이 완료된 후, 할당된 영역의 크기가 가장 큰 포인터를 고르세요.

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int arr[5] = {10, 20, 30, 40, 50};
    int *pa;
    int *pb;
    int *pc;
    int i;

    // 1. pa 할당
    pa = (int *)malloc(sizeof(arr));

    for(i = 0; i < 5; i++)
    {
        pa[i] = arr[i];
    }

    // 2. pb 할당
    pb = (int *)calloc(pa[3], sizeof(int));
    
    // 3. pc 할당
    pc = (int *)realloc(NULL, pa[4]);

    return 0;
}

질문: pa, pb, pc 중 할당된 메모리 크기가 가장 큰 것은?

정답: pb

해설:

각 포인터에 할당된 메모리 크기를 계산해 보겠습니다.

  • pa 할당: malloc(sizeof(arr))
    • sizeof(arr) = sizeof(int) × 5 = 4 × 5 = 20바이트
  • pb 할당: calloc(pa[3], sizeof(int))
    • pa[3] = 40 (배열에서 복사된 값)
    • calloc(40, sizeof(int)) = 40 × 4 = 160바이트
    • calloc은 모든 바이트를 0으로 초기화합니다
  • pc 할당: realloc(NULL, pa[4])
    • pa[4] = 50 (배열에서 복사된 값)
    • realloc(NULL, 50) = 50바이트
    • realloc의 첫 번째 인자가 NULL이면 malloc과 동일하게 동작

크기 비교:

  • pa: 20바이트
  • pb: 160바이트 ✓ (가장 큼)
  • pc: 50바이트

주요 개념:

  • malloc(size): size 바이트만큼 메모리 할당 (초기화 안 함)
  • calloc(n, size): n × size 바이트만큼 메모리 할당 (0으로 초기화)
  • realloc(ptr, size): ptr이 NULL이면 malloc과 동일, 아니면 크기 재조정

문제 6: 동적 배열을 이용한 평균과 표준편차 계산

사용자로부터 학생 수 n을 입력받아, malloc()을 사용하여 double형 배열을 동적으로 할당하세요. n명의 학생 점수를 입력받아 저장한 후, 평균과 표준편차를 계산하여 출력하고 메모리를 해제하세요.

표준편차 공식: √(Σ(x - 평균)² / n)

입력 예시:

5
85.5 90.0 78.5 92.0 88.0

출력 예시:

평균: 86.80
표준편차: 4.67
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

int main() {
    int n;
    double *scores;
    double sum = 0, mean, variance = 0, std_dev;
    
    printf("학생 수 입력: ");
    scanf("%d", &n);
    
    // 동적 메모리 할당
    scores = (double*)malloc(n * sizeof(double));
    if (scores == NULL) {
        printf("메모리 할당 실패\n");
        return 1;
    }
    
    // 점수 입력
    printf("점수 입력: ");
    for (int i = 0; i < n; i++) {
        scanf("%lf", &scores[i]);
        sum += scores[i];
    }
    
    // 평균 계산
    mean = sum / n;
    
    // 분산 계산
    for (int i = 0; i < n; i++) {
        variance += pow(scores[i] - mean, 2);
    }
    variance /= n;
    
    // 표준편차 계산
    std_dev = sqrt(variance);
    
    printf("평균: %.2lf\n", mean);
    printf("표준편차: %.2lf\n", std_dev);
    
    // 메모리 해제
    free(scores);
    
    return 0;
}

  • 숫자형(%f)만 입력받는 경우 scanf_s와 scanf의 사용법은 동일
  • sqrt(), pow() 사용 시 #include <math.h> 필요

문제 3: 학생 3명의 평균 점수 구하기 ⭐⭐

구조체 배열을 활용해 여러 명의 데이터를 처리하세요.

[조건]

  • 구조체 이름: Student
  • 멤버: 이름(name), 점수(score, 정수)
  • 학생 3명의 정보를 입력받아 평균 점수를 출력할 것

[실행 예시]

학생 1 - 이름: 철수  점수: 80
학생 2 - 이름: 영희  점수: 90
학생 3 - 이름: 민준  점수: 75

=== 결과 ===
철수: 80점
영희: 90점
민준: 75점
평균: 81.67점
#include <stdio.h>

struct Student {
    char name[20];
    int score;
};

int main() {
    struct Student s[3];
    int total = 0;

    for (int i = 0; i < 3; i++) {
        printf("학생 %d - 이름: ", i + 1);
        scanf_s("%s", s[i].name, sizeof(s[i].name));  // 배열 요소도 동일하게
        printf("학생 %d - 점수: ", i + 1);
        scanf_s("%d", &s[i].score);
        total += s[i].score;
    }

    printf("\n=== 결과 ===\n");
    for (int i = 0; i < 3; i++) {
        printf("%s: %d점\n", s[i].name, s[i].score);
    }
    printf("평균: %.2f점\n", (float)total / 3);

    return 0;
}

핵심 포인트

  • 구조체 배열 접근: s[i].멤버명
  • 구조체 배열 요소의 문자열 입력 시에도 sizeof(s[i].name)으로 버퍼 크기 전달
  • for문으로 반복 입력/출력 처리

문제 4: 두 사각형 중 넓이가 큰 것 출력하기 ⭐⭐

구조체와 함수를 함께 활용해보세요.

[조건]

  • 구조체 이름: Rectangle
  • 멤버: 가로(width), 세로(height) → 정수형
  • 두 사각형의 정보를 입력받아 넓이를 비교하고 더 큰 사각형의 정보를 출력할 것
  • 넓이를 계산하는 함수 getArea()를 별도로 만들 것

[실행 예시]

사각형1 - 가로: 4  세로: 5
사각형2 - 가로: 3  세로: 8
사각형1 넓이: 20
사각형2 넓이: 24
더 큰 사각형: 사각형2 (가로: 3, 세로: 8)
#include <stdio.h>

struct Rectangle {
    int width;
    int height;
};

int getArea(struct Rectangle r) {
    return r.width * r.height;
}

int main() {
    struct Rectangle r1, r2;

    printf("사각형1 - 가로: ");
    scanf_s("%d", &r1.width);
    printf("사각형1 - 세로: ");
    scanf_s("%d", &r1.height);

    printf("사각형2 - 가로: ");
    scanf_s("%d", &r2.width);
    printf("사각형2 - 세로: ");
    scanf_s("%d", &r2.height);

    int area1 = getArea(r1);
    int area2 = getArea(r2);

    printf("\n사각형1 넓이: %d\n", area1);
    printf("사각형2 넓이: %d\n", area2);

    if (area1 > area2)
        printf("더 큰 사각형: 사각형1 (가로: %d, 세로: %d)\n", r1.width, r1.height);
    else if (area2 > area1)
        printf("더 큰 사각형: 사각형2 (가로: %d, 세로: %d)\n", r2.width, r2.height);
    else
        printf("두 사각형의 넓이가 같습니다.\n");

    return 0;
}

핵심 포인트

  • 구조체를 함수의 매개변수로 전달하는 방법
  • 정수형(%d) 입력은 scanf_s와 scanf 사용법이 동일
  • 값에 의한 전달(call by value)이므로 원본은 변경되지 않음

문제 5: 포인터로 구조체 멤버 수정하기 ⭐⭐⭐

구조체 포인터와 화살표 연산자를 사용해보세요.

[조건]

  • 구조체 이름: BankAccount
  • 멤버: 이름(name), 잔액(balance, 정수)
  • 구조체 포인터를 매개변수로 받는 deposit() 함수를 만들 것
  • deposit() 함수 안에서 잔액을 직접 수정할 것 (포인터 사용)

[실행 예시]

계좌주: 홍길동
초기 잔액: 10000

입금액 입력: 5000

=== 입금 완료 ===
계좌주: 홍길동
현재 잔액: 15000
#include <stdio.h>

struct BankAccount {
    char name[20];
    int balance;
};

void deposit(struct BankAccount *acc, int amount) {
    acc->balance += amount;
}

int main() {
    struct BankAccount account;

    printf("계좌주: ");
    scanf_s("%s", account.name, sizeof(account.name));  // 버퍼 크기 전달
    printf("초기 잔액: ");
    scanf_s("%d", &account.balance);

    int amount;
    printf("\n입금액 입력: ");
    scanf_s("%d", &amount);

    deposit(&account, amount);

    printf("\n=== 입금 완료 ===\n");
    printf("계좌주: %s\n", account.name);
    printf("현재 잔액: %d\n", account.balance);

    return 0;
}

핵심 포인트

  • 함수에서 구조체를 수정하려면 포인터로 전달해야 함 → &account
  • 포인터로 멤버 접근 시 화살표(->) 연산자 사용 → acc->balance
  • (*acc).balance와 acc->balance는 동일한 표현
  • 문자열 입력 시 sizeof(account.name)으로 버퍼 크기를 반드시 전달

📌 scanf vs scanf_s 차이 한눈에 보기

입력 타입 scanf scanf_s
정수 %d scanf("%d", &n) scanf_s("%d", &n) → 동일
실수 %f scanf("%f", &f) scanf_s("%f", &f) → 동일
문자열 %s scanf("%s", str) scanf_s("%s", str, sizeof(str)) → 버퍼 크기 추가
문자 %c scanf("%c", &ch) scanf_s("%c", &ch, 1) → 크기 1 추가

⚠️ 주의: scanf_s는 Visual Studio(Windows) 환경에서 권장합니다. GCC(Linux/Mac) 환경에서는 지원되지 않을 수 있습니다.
